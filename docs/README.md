## Overview

The HAVEN project is a comprehensive emergency response system consisting of three main components:

1. **Mobile App** - React Native application for users to send emergency alerts
2. **Desktop App** - Java Swing application for emergency response units to monitor alerts
3. **Backend** - Node.js API server that facilitates communication between components

Each component has its own documentation to help developers understand and maintain the system effectively.
