This folder contains all documentation related to the HAVEN database system.

## Contents

- **RED_MARKER_IMPLEMENTATION.md** - Implementation details for red marker functionality

## Overview

The HAVEN application uses CSV files for data persistence, providing a simple yet effective data storage solution. Key components include:

- User registration data
- Emergency alert records
- Response unit information
- System configuration settings

The database system is designed to be lightweight and easy to maintain while providing reliable data storage for the emergency response system.
