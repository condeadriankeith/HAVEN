## Overview

The responsive design system ensures that the HAVEN mobile application provides a consistent and optimal user experience across various device sizes, orientations, and platforms.

## Key Components

- **Responsive Utilities**: Scaling functions for consistent UI across devices
- **Responsive Dimensions Hook**: Automatic dimension updates on screen rotation
- **Safe Area Wrapper**: Handles notches and system bars
- **Enhanced Design System**: Extended spacing and typography options
- **Orientation Support**: Support for both portrait and landscape modes

For detailed information about each component and implementation details, please refer to the individual documentation files.
