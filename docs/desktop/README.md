## Contents

- **DESKTOP_README.md** - Original README from the desktop app directory
- **Desktop_App_UI_UX_Revolution_PRD.md** - UI/UX design document for the desktop application

## Overview

The HAVEN desktop app is built with Java Swing, providing a comprehensive interface for emergency response units to monitor and respond to alerts. Key features include:

- Live map displaying emergency alerts from mobile users
- Real-time alert monitoring
- Emergency response coordination
- User management interface
- Integration with the mobile application via REST API

The desktop app receives emergency alerts from the mobile application through the backend API server and displays them on an interactive map for emergency response units to act upon.
